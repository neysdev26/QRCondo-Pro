Política de Privacidade – QrCondo Pro

Última atualização: 14 de julho de 2026

A sua privacidade é importante para nós. Esta Política de Privacidade explica como o aplicativo QrCondo Pro coleta, usa, armazena e protege as informações fornecidas pelos usuários ao utilizar o aplicativo. Ao utilizar o aplicativo, você concorda com as práticas descritas nesta política.

1. Responsável pelo tratamento dos dados

Desenvolvedor: Ney S.

E-mail de contato: neysdev@gmail.com

Aplicativo: QrCondo Pro – Gestão de Encomendas para Condomínios

2. Que dados coletamos?

O aplicativo pode coletar as seguintes categorias de dados pessoais:

  • Dados cadastrais: nome, bloco, apartamento, e-mail.
  • Dados de encomendas: remetente, destinatário, código QR, observações, data de chegada e retirada, porteiro responsável.
  • Dados de autenticação: credenciais de login e token de acesso.
  • Dados de assinatura digital: imagem da assinatura do recebedor.
  • Dados de câmera: apenas para leitura de QR Code; as imagens não são armazenadas.
  • Dados de dispositivo: modelo, sistema operacional, idioma.

3. Como usamos seus dados?

  • Gerenciar encomendas dentro do condomínio.
  • Identificar destinatários e unidades.
  • Emitir comprovantes de entrega com assinatura digital.
  • Enviar notificações sobre encomendas.
  • Melhorar o aplicativo e corrigir falhas.
  • Manter registros de auditoria.

4. Compartilhamento de dados

Não vendemos ou compartilhamos dados para marketing. Os dados podem ser compartilhados com:

  • Condomínio responsável: para gestão das entregas.
  • Provedores de serviço: Supabase para armazenamento.
  • Exigência legal: quando obrigatório por lei.

5. Armazenamento e segurança

Os dados são armazenados em servidores seguros (Supabase) com criptografia em trânsito (TLS) e em repouso (AES-256). O acesso é restrito a usuários autenticados.

6. Seus direitos

Você tem direito a:

  • Acessar, corrigir ou excluir seus dados.
  • Revogar consentimento.
  • Solicitar portabilidade dos dados.
  • Opor-se ao tratamento para finalidades específicas.

7. Retenção de dados

Os dados são mantidos pelo tempo necessário para gestão condominial e obrigações legais. Assinaturas são armazenadas enquanto o histórico for mantido.

8. Cookies

O aplicativo não utiliza cookies, mas pode utilizar tokens de autenticação e armazenamento local.

9. Alterações nesta Política

Esta política pode ser atualizada periodicamente. A versão mais recente estará disponível nesta página.
